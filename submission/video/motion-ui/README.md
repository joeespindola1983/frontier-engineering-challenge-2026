# Interface interaction motion

These original vector overlays provide a consistent cursor, click pulse, and
scroll cue for the submission video. They are used only when a visible action
explains the next product state: revealing lower-page evidence, opening a crew
or competition record, loading the post-regatta period, or reaching evaluation
detail. They do not imply that a pre-rendered draft is a live model execution.

`agentic-flow.svg` is the casual technical interlude used after evidence
intake. It truthfully depicts one bounded investigation agent, four
deterministic tools, a verifier, and the athlete/coach decision boundary. It
does not present the workflow as a multi-agent system.
